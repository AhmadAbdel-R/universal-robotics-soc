## Methodology Overview

The engineering documentation relies strictly on verified physical principles, theoretical models, and established fabrication constraints. Claims are classified under the following categories: THEORY, DATASHEET REQUIREMENT, FABRICATOR CONSTRAINT, CALCULATION, SIMULATION, MEASUREMENT, DESIGN CHOICE, ASSUMPTION, or TBD.
