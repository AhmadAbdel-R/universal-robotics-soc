# Power Distribution Network (PDN)

## PDN Overview

(THEORY)
The Power Distribution Network encompasses everything from the voltage regulator module to the die of the IC. It relies heavily on the PCB stackup and physical layout to maintain Power Integrity (PI).

## Plane Spacing and Capacitance

(THEORY)
The spacing between adjacent power and ground planes strongly influences the PDN impedance profile:
- Spreading inductance is reduced with closer plane spacing.
- Distributed planar capacitance is increased, which helps supply high-frequency transient current demands.
- A closer plane spacing minimizes the loop area for return currents, which in turn reduces loop inductance.
