# STM32CubeMX Configurations

This directory will contain the STM32CubeMX configuration artifacts and exported pinout mappings.

These files act as configuration-controlled design inputs and are strictly verified before KiCad schematic capture begins.

## Pending Files
- `universal-robotics-soc.ioc`: The main STM32CubeMX project file (to be created during the verification stage).
- `pinout.csv`: The exported pin assignments (to be generated).
